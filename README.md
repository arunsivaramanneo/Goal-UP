# GOAL-UP

Goal UP is a streamlined Gtk4-based productivity tool designed to help you track your long-term goals and daily tasks with powerful visual feedback and GNOME integration.

🚀 Key Features
Goal & Task Hierarchy: Organize your life by grouping specific tasks under high-level goals.
Dependency Management: Set parent-child relationships between goals and tasks to build a structured roadmap.

Visual Progress Tracking:
Pie Charts: Real-time visualization of goal and task completion percentages.
Trend Bar Graphs: Track your monthly completion history.
Timeline View: A chronological overview of your upcoming and completed items.
Progress Metrics: Automatically calculated "Days Elapsed" and "Days Remaining" for time-bound objectives.

GNOME Integration:
Shell Extension: Quick access to your deadlines and progress charts directly from the GNOME top bar.
Native Notifications: Stay alerted about overdue tasks and upcoming deadlines.

Data Portability:
Export to ICS: Sync your deadlines with standard calendar applications (Google Calendar, Outlook, etc.).
Backup & Restore: Easily move your data between systems using JSON backups.

✅ What You Can Do
Visualize Success: See exactly how much progress you've made at a glance through clean, color-coded charts.
Plan Ahead: Use the timeline and deadline tracking to ensure you're always aware of what's next.
Organize Complexity: Break down large, daunting goals into manageable sub-tasks with dependencies.
Own Your Data: All your tasks are stored locally on your machine in ~/.local/share/goal-up/.
Stay Notified: Receive desktop alerts for tasks due today without having to keep the app open.

⚠️ Current Limitations (What You Can't Do Yet)
Cloud Sync: Goal-UP is currently local-only. There is no built-in sync across multiple devices (web/mobile).
Collaboration: This is a personal productivity tool; it does not support shared goals or team features.
Recurring Tasks: You must manually create each task; automated recurring schedules (daily/weekly) are not yet supported.
Rich Text Support: Goal and task descriptions currently support plain text only.


To install just clone the application and run ./install
