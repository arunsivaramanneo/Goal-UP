# GOAL-UP
Its Just a Simple To Do List Application built with AI. Users Can Add Goals and add Tasks to specific goal. Each Goal on high level shows the summary of the Goal like number of Tasks completed . % complete , No of days Elapsed and if you have put and end date it will show the no of days left to achieve the Goal
