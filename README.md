# GOAL-UP
Its Just a Simple To Do List Application built with AI. Users Can Add Goals and add Tasks to specific goal. Each Goal on high level shows the summary of the Goal like number of Tasks completed . % complete , No of days Elapsed and if you have put an end date it will show the no of days left to achieve the Goal. Also , it gives a timeline of the tasks that has been completed and the tasks through the year (Note : it will only display if the end date is added to the task/Goal or when user selects the task is complete)
